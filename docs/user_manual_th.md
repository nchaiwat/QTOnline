# คู่มือการใช้งานระบบ PO-Online (User Manual)

ระบบ PO-Online ออกแบบมาเพื่อช่วยในการจัดการใบสั่งซื้อ (Purchase Order) ของบริษัท วินโดว์ เอเชีย จำกัด (มหาชน) ให้มีความรวดเร็ว ถูกต้อง และตรวจสอบได้

---

## 1. การเข้าสู่ระบบ (Login)
1. เข้าสู่ระบบด้วย **Username** และ **Password** ที่ได้รับจาก Administrator
2. **ระบบ Idle Timeout:** หากไม่มีการเคลื่อนไหวเกิน 10 นาที ระบบจะออกจากระบบอัตโนมัติเพื่อความปลอดภัย

---

## 2. แดชบอร์ด (Dashboard)
เป็นหน้าแรกหลังจากเข้าสู่ระบบ แสดงภาพรวมของงาน:
- **สถิติรายวัน/รายสัปดาห์:** จำนวน PO ที่สร้างใหม่
- **ยอดอนุมัติเดือนนี้:** แสดงยอดรวมเงินและจำนวนใบสั่งซื้อที่อนุมัติแล้ว
- **สถานะใบสั่งซื้อ (Status Funnel):** กราฟแสดงจำนวน PO ในแต่ละขั้นตอน (Draft -> Pending -> Approved -> Completed)
- **กิจกรรมล่าสุด:** ลำดับเหตุการณ์ที่เกิดขึ้นในระบบ

---

## 3. การจัดการใบสั่งซื้อ (PO Management)
เมนูหลักสำหรับการทำงานรายวันของผู้ใช้:

### 3.1 การสร้าง PO ใหม่ (เฉพาะ Sale)
1. คลิกปุ่ม **"Create New PO"**
2. **เลือกลูกค้า:** ค้นหาและเลือกลูกค้าจากฐานข้อมูล
3. **ระบุรายละเอียด:** วันที่ส่งสินค้า (Delivery Date) และข้อมูลอื่น ๆ
4. **เพิ่มสินค้า:** ค้นหาสินค้า ระบุจำนวน และยอดส่วนลด (ถ้ามี)
5. **บันทึก:** เลือก **"Save Draft"** (เพื่อแก้ไขต่อภายหลัง) หรือ **"Submit for Review"** (เพื่อส่งให้ Admin อนุมัติ)

### 3.2 การอนุมัติและจัดการสถานะ (Sale Admin / Admin)
- **Pending Review:** ตรวจสอบรายละเอียด PO ที่ส่งมา
- **Approve:** กดอนุมัติหากข้อมูลถูกต้อง
- **Request Changes:** กดขอแก้ไขหากต้องการให้ Sale ปรับปรุงข้อมูล (ใส่ Comment ประกอบ)
- **Cancel PO:** จัดการคำขอรอยกเลิกจาก Sale

### 3.3 การจัดการเอกสาร (Document Upload)
ในหน้ารายละเอียด PO (PO Detail) สามารถจัดการเอกสารได้ดังนี้:
- **Signed PO:** อัปโหลดใบสั่งซื้อที่ลงนามแล้ว (PDF)
- **Customer Map:** อัปโหลดแผนที่หรือตำแหน่งของลูกค้า (JPG/PNG/PDF)
- **Customer PO:** อัปโหลดใบสั่งซื้อต้นฉบับจากลูกค้า (JPG/PNG/PDF)

---

## 4. การจัดการข้อมูลลูกค้าและสินค้า (Customers & Products)
- **ค้นหา:** ใช้ช่อง Search เพื่อหาข้อมูลตามรหัส หรือชื่อ
- **ตัวกรองสถานะ:** เลือกดูเฉพาะข้อมูลที่ Active หรือ Inactive
- **การนำเข้าข้อมูล (Import):**
  1. ดาวน์โหลดไฟล์ตัวอย่าง (Download Template)
  2. กรอกข้อมูลในไฟล์ CSV ตามรูปแบบที่กำหนด
  3. อัปโหลดไฟล์ (Upload File) เข้าสู่ระบบ

---

## 5. ข้อมูลส่วนตัวและลายเซ็น (User Settings)
- **เปลี่ยนรหัสผ่าน:** คลิกไอคอนกุญแจที่มุมขวาบนเพื่อตั้งรหัสผ่านใหม่
- **จัดการลายเซ็น:** คลิกไอคอนปากกาเพื่อวาดและบันทึกลายเซ็นดิจิทัล สำหรับใช้ในเอกสาร PDF ที่ระบบสร้างขึ้น

---

## 6. ลำดับสถานะใบสั่งซื้อ (Workflow Status)
- **Draft:** ร่าง (แก้ไขได้ ลบได้)
- **Pending Review:** รอการตรวจสอบ (รอ Admin อนุมัติ)
- **Approved:** อนุมัติแล้ว (เตรียมดำเนินการขั้นต่อไป)
- **Changes Requested:** ถูกขอให้แก้ไข (Sale ต้องแก้ไขตาม Comment)
- **Completed:** เสร็จสมบูรณ์ (อัปโหลดเอกสารครบถ้วน)
- **Cancellation Requested:** รออนุมัติการยกเลิก
- **Cancelled:** ยกเลิกแล้ว
